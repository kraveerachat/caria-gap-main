# Company logos — Company Directory (zig-zag cards)

Drop logo files here to replace the text-wordmark fallback used by
`components/CompanyDirectory.tsx` (the `/company-directory` route).

- Format: **PNG** (`.png`), transparent background recommended.
- Filename must match the company name **exactly** — capitalization, spaces, and
  parentheses included. The card renders the logo centered on a white plate, so
  colour or monochrome artwork both work. Missing file → clean wordmark fallback.
- Served from the site root: a file `Google.png` here is referenced as `/logos/Google.png`.
